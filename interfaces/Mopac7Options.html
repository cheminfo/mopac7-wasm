    Optionalkeywords

    keywords?: readonly string[]

    Extra MOPAC keywords, appended to the first line of the deck, one array entry per keyword. Each is checked first: whitespace, +, SETUP and UHF are refused with code: 'input', because they would shift the deck's own lines or produce a listing this package cannot read.

    Default

    Optionalspin

    spin?: Mopac7Spin

    Spin state. Anything but 'singlet' writes MOPAC's multiplicity keyword, and MOPAC 7 then runs its RHF half-electron treatment. There is no unrestricted option: 'UHF' in Mopac7Options.keywords is refused, because its listing has separate alpha and beta eigenvectors and Mopac7Result holds one set.

    Default

    'singlet'
